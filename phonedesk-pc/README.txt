PhoneDesk Windows v0.2

Easy Windows client for pairing with and controlling your own Android phone over Android Wireless Debugging.

EASY SETUP
1. On Android enable Developer options and Wireless debugging.
2. Choose “Pair device with pairing code” and keep that popup open.
3. Open PhoneDesk.exe on Windows.
4. Click FIND MY PHONE. PhoneDesk discovers the IP and pairing port automatically.
5. Enter only the temporary 6-digit code shown by Android.
6. Click PAIR & CONNECT. PhoneDesk discovers the normal connection port automatically.
7. Click CONTROL PHONE.

MANUAL FALLBACK
If automatic discovery is blocked by your Wi-Fi/network, open “Manual setup” and enter the values shown by Android.

IMPORTANT
- The six-digit pairing code is never saved.
- PhoneDesk saves only the trusted phone IP/device port and screen-off preference.
- The phone and PC should be on the same reachable network for this local-control version.
- Do not expose ADB directly to the public internet.
- Some banking/DRM apps can intentionally block screen capture or require separate authentication.
- After reboot, Android may require a local unlock before all services become available.

CONTENTS
- PhoneDesk.exe — PhoneDesk Windows UI
- adb.exe / Android platform tools — pairing and trusted connections
- scrcpy.exe and support files — low-latency Android screen/control

PhoneDesk does not store your Android lock PIN, password, pattern, fingerprint, or temporary Wireless Debugging pairing code.
