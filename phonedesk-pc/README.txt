PhoneDesk Windows v0.1

Portable Windows client for pairing with and controlling your own Android phone over Android Wireless Debugging.

FIRST-TIME SETUP
1. On Android enable Developer options and Wireless debugging.
2. In Wireless debugging choose “Pair device with pairing code”.
3. Open PhoneDesk.exe on Windows.
4. Enter the phone IP, pairing port, and temporary 6-digit code.
5. Click PAIR.
6. Return to the main Wireless debugging screen on Android.
7. Enter the normal Wireless debugging device port in PhoneDesk.
8. Click CONNECT.
9. Click START PHONE CONTROL.

IMPORTANT
- The six-digit pairing code is never saved.
- PhoneDesk saves only the trusted phone IP/device port and screen-off preference.
- The phone and PC should be on the same reachable network for this version.
- Do not expose ADB directly to the public internet.
- Some banking/DRM apps can intentionally block screen capture or require separate authentication.
- After reboot, Android may require a local unlock before all services become available.

CONTENTS
- PhoneDesk.exe — PhoneDesk Windows UI
- adb.exe / Android platform tools — used for pairing and trusted connections
- scrcpy.exe and support files — used for low-latency Android screen/control

PhoneDesk does not store your Android lock PIN, password, pattern, fingerprint, or temporary Wireless Debugging pairing code.
